Backup Integrations
===================

|morpheus| integrates with several third-party backup providers to extend the built-in backup capabilities. Once integrated, these providers can be set as the default backup solution for compatible Clouds, enabling automated backup scheduling during Instance provisioning and easy restoration when needed.

Open this view from :menuselection:`Backups --> Integrations`. The Integrations navigation item is shown only to users whose Role permits access to Backup Services.
