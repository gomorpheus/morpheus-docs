Host Console
------------

.. versionadded:: 9.1
   Host administrators can manage a host's virtual machines and consoles from a browser, served directly by the host agent.

The Host Console lets a signed-in host administrator view the host's virtual machines and their state, resources, and IP addresses; run power actions — **Power On**, **Shut Down**, **Restart**, **Suspend**, **Resume**, **Reset**, and **Power Off**; open a VM's graphical console in the browser; and copy a VM's IP address or inspect its network interfaces. It runs entirely on the host and does not require SSH access.
