Migrations
==========

The bulk migration tool enables VMware vCenter workloads to be migrated to HVM (HPE Morpheus Virtual Machine) Clusters. Migration Plans orchestrate the end-to-end process: preparing source VMs, streaming disk data, converting storage formats, and bringing workloads online on the target HVM infrastructure. Both Linux and Windows workloads are supported, with automated VirtIO driver injection for Windows guests.
