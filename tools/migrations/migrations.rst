Migrations
==========

The bulk migration tool is designed to migrate existing VMs running on integrated VMware vCenter Clouds to HVM Clusters. Thus, creating a migration requires existing vCenter Cloud integration(s) and at least one functional HVM Cluster. See the VMware vCenter integration guide and the HVM Clusters guide elsewhere in this documentation stack for more details on getting started with and using those integrations. Migrations may include multiple VMs and may include both Linux and Windows workloads.
