# Infrastructure Networking Overhaul

## Objective

Improve the Infrastructure > Networks documentation with screenshots, VMware-to-HVM analogies, and step-by-step walkthroughs. Partners and customers consistently struggle with this section.

## Acceptance Criteria

1. Step-by-step guide for creating a new network in Morpheus
2. VMware-to-Morpheus analogy table (port groups → networks, vSwitches → virtual switches, etc.)
3. Screenshots of key UI screens for network creation workflow
4. Covers replicating a common VMware network design in Morpheus/HVM
5. Explains network types and when to use each
6. Written for users who understand VMware networking but are new to Morpheus

- `infrastructure/networks/` — Overhaul existing files, add screenshots and guides
