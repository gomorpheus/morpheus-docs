# HVM Cluster Content for Essentials

## Objective

Ensure the Essentials documentation covers HVM cluster operations with the same depth as the Enterprise guide — particularly day-0 ops, cluster startup, network management, and ongoing day-2 operations.

## Acceptance Criteria

1. Day-0 cluster setup and startup procedures are documented for Essentials users
2. Network creation and management within HVM clusters is covered
3. Day-2 operations (adding hosts, storage changes, maintenance) are included
4. Content is adapted for Essentials scope (not just copied verbatim from Enterprise)
5. Gaps between Essentials and Enterprise docs are identified and closed where applicable
