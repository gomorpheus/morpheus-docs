# HPE Morpheus Enterprise Documentation Site

## Objective

Maintain and improve the HPE Morpheus Enterprise documentation site — a Sphinx/RST-based docs project hosted on ReadTheDocs. The site covers all aspects of the Morpheus platform including installation, operations, provisioning, infrastructure management, monitoring, administration, and integrations.

## Surfaces

| Surface | Description | Status |
|---------|-------------|--------|
| Getting Started | Installation, system requirements, initial setup | active |
| Operations | Day-to-day operational workflows | active |
| Provisioning | Instance, app, and resource provisioning | active |
| Library | Reusable templates, option lists, specs | active |
| Infrastructure | Cloud, network, and compute management | active |
| Backups | Backup configuration and jobs | active |
| Monitoring | Checks, alerts, incidents, contacts | active |
| Tools | Cypher, archives, VDI, image builder | active |
| Administration | Tenants, roles, policies, settings | active |
| Personas | Alternate UI persona docs | active |
| Integration Guides | Third-party integrations (ServiceNow, etc.) | active |
| Troubleshooting | Common issues and resolutions | active |
| Security | Security hardening and compliance | active |
| Release Notes | Per-version changelogs and compatibility | active |

- All sections are accurate for the current Morpheus release
- No broken cross-references or dead links
- Consistent formatting and style across all sections
- New features documented within the same release cycle
