# 9.1.0 Docs: HVM Network Plugin - Linux-Bridge/virtSwitch

## Summary

Document the extension of the HVM Network Plugin to support Linux-Bridge/virtSwitch. This enables decoupled networking management through a dedicated plugin via the Network Provider framework.

## Scope

- HVM Network Plugin architecture for Linux-Bridge/virtSwitch
- Configuration steps for enabling Linux-Bridge networking on HVM clusters
- Network type options: standard, private, data, overlay
- Migration considerations from existing network configurations
- Troubleshooting guide for Linux-Bridge/virtSwitch issues
