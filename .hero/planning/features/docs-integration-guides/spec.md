# Docs: Integration Guides

## Purpose

In-depth guides for complex third-party integrations including ServiceNow, Terraform, Ansible, and cloud-specific deep-dives.

## Scope

- `integration_guides/` directory
- ServiceNow plugin and CMDB
- Terraform and IaC integrations
- Configuration management (Ansible, Puppet, Chef)
- Cloud-specific guides (AWS, Azure, GCP, VMware)
- Networking integrations (NSX, ACI, etc.)

## Goals

- End-to-end integration walkthroughs
- Prerequisite checklists for each integration
- Troubleshooting sections per integration
