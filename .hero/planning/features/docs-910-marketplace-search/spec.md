# 9.1.0 Docs: Plugin Marketplace Search

## Summary

Document the ability to search and browse plugins from share.morpheusdata.com directly within the Morpheus UI plugin section, with automatic compatibility filtering by appliance version.

## Acceptance Criteria

1. Document the marketplace search/browse interface within the Plugins section of the UI.
2. Document the automatic compatibility filter: only plugins matching the current appliance version are shown.
3. Document network requirements: the appliance must have outbound access to share.morpheusdata.com:443.
4. Document what information is shown per plugin (description, compatibility notes, version).
5. Note proxy configuration requirements for environments with restricted outbound access.
