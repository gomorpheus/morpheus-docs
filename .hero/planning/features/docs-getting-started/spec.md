# Docs: Getting Started

## Purpose

Covers system requirements, installation guides (single-node, HA, distributed), initial appliance setup, and first-login configuration for HPE Morpheus Enterprise.

## Scope

- `getting_started/` directory
- Installation procedures for all supported platforms
- System requirements and compatibility matrices
- Initial configuration and setup wizards

## Goals

- Keep installation docs current with each release
- Cover all supported OS/DB/platform combinations
- Provide clear upgrade paths between versions
