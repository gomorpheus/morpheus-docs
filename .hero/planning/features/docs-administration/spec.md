# Docs: Administration

## Purpose

Covers tenant management, roles/permissions, policies, settings, integrations, and identity management.

## Scope

- `administration/` directory
- Tenants and user management
- Roles and permissions
- Policies (naming, sizing, budgets, etc.)
- Global settings and whitelabel
- Identity sources (LDAP, SAML, etc.)
- Integrations management

## Goals

- Complete RBAC/permissions reference
- Policy configuration guide
- Identity source integration docs for all supported providers
