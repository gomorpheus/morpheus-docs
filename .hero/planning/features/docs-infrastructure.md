# Docs: Infrastructure

## Purpose

Covers cloud integrations, groups, networking, storage, keys/certs, and compute resource management.

## Scope

- `infrastructure/` directory
- Cloud integrations (AWS, Azure, GCP, VMware, etc.)
- Groups, networks, load balancers
- Storage, keys & certs, boot scripts
- Clusters (Kubernetes, Docker, etc.)

## Goals

- Per-cloud integration guides with full field-level documentation
- Network and storage configuration references
- Cluster management lifecycle docs
