# Docs: Release Notes

## Purpose

Per-version changelogs, new feature announcements, deprecation notices, and compatibility matrices.

## Scope

- `release_notes/` directory
- Per-release changelog documents
- Compatibility matrix (supported browsers, DBs, OS, etc.)
- Migration/upgrade notes

## Goals

- Release notes published with each version
- Compatibility matrix kept current
- Clear deprecation and breaking change callouts
