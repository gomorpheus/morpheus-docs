.. _Release Notes 8.1.0:

****************************************
v8.1.0 Historical Feature Release Notes
****************************************

This page records selected 8.1.0 release items added retrospectively from Jira
and customer case records. Statements about current product
behavior are identified separately and do not expand the historical release's
compatibility claims.

Selected 8.1.0 Enhancements
===========================

:Branding: - MORPH-10132: Version 8.1.0 changed the default product branding and visual presentation from Morpheus branding to HPE branding. This visual update did not represent a functional change. HPE branding remains the current default.

:Infoblox Integration: - MORPH-10134: The 8.1.0 release input identifies Infoblox plugin version 1.5.1, updated February 24, 2026. The plugin is obtained from the Morpheus Plugin Catalog (Marketplace). This historical version statement applies to the identified plugin release; it does not assert compatibility with every Infoblox or |morpheus| version.

Selected 8.1.0 Fixes
====================

:Authentication: - MORPH-10130 / case 5392395910: Fixed the expired-password flag behavior for local |morpheus| accounts. Current product behavior continues to enforce the flag for local accounts.

:Service Catalog: - MORPH-10131 / case 5392804959: The 8.1.0 release record reports a fix for ``catalogError`` when using ``customoption.cloud.split``. The statement is limited to this expression and reported case.

:Plugins: - MORPH-10133 / case 5401996862: Fixed the reported loss of the option to disable plugins in the GUI and API. The current GUI provides plugin enable and disable controls; the historical API scope is attributed to the case and 8.1.0 release input.
