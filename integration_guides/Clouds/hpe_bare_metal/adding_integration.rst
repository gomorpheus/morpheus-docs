Adding HPE BMaaS Integration
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Prerequisites
`````````````

This procedure describes how to integrate HPE BMaaS with your |morpheus| Enterprise environment.

About this task
```````````````

To install the **HPE BMaaS** plugin, perform the following steps:

#. Log in to the HPE |morpheus| Enterprise Software web interface using your administrator credentials.
#. Navigate to :menuselection:`Administration --> Integrations`.
#. Select the Plugins tab and click :guilabel:`Add` button.
#. Drag the HPE BMaaS ``JAR`` file into the :guilabel:`Drop Files Here` area, or click :guilabel:`Add File` to select it manually.
#. Click :guilabel:`Upload`.

After a successful upload, HPE BMaaS is available for use.
